# БУХАЛ ӨВС — эхний ажиллах хувилбар

Энэ бол тусдаа Supabase төсөлд холбогдох Next.js вебийн эхний хувилбар.

## Одоогоор ажиллах боломжтой
- Нүүр хуудас
- Имэйл + нууц үгээр бүртгүүлэх
- Нэвтрэх, гарах
- Нэвтэрсэн хэрэглэгчийн хувийн аяллын хэсэг
- I үе шатанд тэмдэглэл нэмэх, хадгалах, өмнөх тэмдэглэлээ харах
- Гар утас, компьютерийн responsive дизайн
- Supabase Row Level Security ашиглан хэрэглэгчийн тэмдэглэлийг тусгаарлах

## Анхаарах нь
Энэ нь эхний MVP. Таван үе шатны бүх үйлдэл, 30 хоногийн төлбөртэй эрхийн баталгаажуулалт, хүслийн картын PDF хэвлэлт хараахан бүрэн хийгдээгүй. Одоогоор үе шат 2–5 нь загвар/түр дэлгэцээр харагдана. 30 хоногийн эрхийг зөвхөн frontend дээр шалгаж болохгүй; төлбөрийн систем болон сервер талын entitlement шалгалт нэмэх шаардлагатай.

## 1. Supabase тусдаа төсөл үүсгэх
1. https://supabase.com дээр шинэ Project үүсгэ.
2. Project Settings → API хэсгээс Project URL болон anon/public key ав.
3. Supabase → SQL Editor руу орж `supabase/schema.sql` файлын кодыг бүхэлд нь ажиллуул.
4. Authentication → Providers → Email идэвхтэй эсэхийг шалга.
5. Authentication → URL Configuration дээр хөгжүүлэлтийн үед `http://localhost:3000` URL-ийг нэм.

## 2. Ажиллуулах
Node.js 20.9 буюу түүнээс дээш хувилбар шаардлагатай.

```bash
npm install
```

`.env.example` файлыг хуулж `.env.local` нэртэй болгоод утгуудыг бөглөнө:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Дараа нь:

```bash
npm run dev
```

Хөтөч дээр `http://localhost:3000` нээнэ.

## 3. Нийтлэх
Vercel эсвэл Next.js дэмждэг хостинг ашиглаж болно. Environment Variables хэсэгт дээрх хоёр утгыг оруулна. Supabase Authentication URL Configuration дээр production домэйн болон redirect URL-ийг тохируул.

## Нууцлал
- `service_role` түлхүүрийг хэзээ ч `NEXT_PUBLIC_` хувьсагчид хийж болохгүй.
- SQL-д Row Level Security асаасан.
- Нэвтрэлт Supabase Auth-аар хийгдэнэ.
- Бичлэг бүр user_id-гаар тусгаарлагдана.

## Дараагийн хөгжүүлэлт
1. II үе шатны өгүүлбэрийг өөртөө чиглүүлэх редактор.
2. III үе шатны таван алхмын асуулга, амьсгалын хөдөлгөөнт цагираг.
3. IV үе шатны хүсэлтийн картын CRUD.
4. V үе шатны дүгнэлт ба нэг А4 дээр зургаан карттай PDF.
5. Сервер талын 30 хоногийн эрхийн хүснэгт, төлбөрийн баталгаажуулалт.
6. Сургалтын админ самбар.
